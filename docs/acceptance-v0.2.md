## Admission and lifecycle checks

- Deployed Character request with `max_frames=85` returned HTTP 422 before a claim/start. Supported preview is 17 frames at 1280×720; the graph may pad internal latent frames before trimming the output.
- The 17-frame policy now requires 64 GiB, based on the prior ~54 GiB observed consumption plus headroom. Nine-frame API previews require 56 GiB. Video uses 40/48/60 GiB bounded tiers. Miso's floor was raised to 40 GiB from its measured ~31 GiB delta.
- Warm containers no longer bypass admission. Competing heavy claims fail before model startup. Protected services and unrelated containers cannot enter the reclamation list.
- The real Character → Lip Sync handoff required no manual model/container action. Enough UMA was available, so this verifies automatic startup/claims/release, not a pressure-forced reclamation. Unit tests cover the insufficient-memory path.
- The host's legacy Lip Sync warm timeout was 1800 seconds. It was aligned to 300 seconds after the render; the supervisor was restarted with no active claims and adopted the idle backend for a fresh five-minute window.
- LatentSync probes input media before inference: at most 10 seconds, 1080p-equivalent pixels and 30 fps. Its 10-second ceiling is a conservative guardrail, not a claim that every setting at that ceiling is validated.
- Missing readiness data, including an HTTP 200 body declaring missing models, fails preparation. Claims are released on errors. Stopped Lip Sync is labeled available on demand only when checkpoints exist; runtime readiness is still checked after startup.

## Genuine unresolved work

- Avatar: the isolated uv resolver on Python 3.12/ARM64 rejects upstream TensorFlow 2.15. Decord also needs a compatible inference path. EchoMimicV3-Flash remains the single proof candidate, with no enabled runtime/UI generation.
- Character Animate: no distinct validated graph; remains unavailable.
- Voice comparison: working voices remain pending a controlled quality/capability comparison. Removing a disabled scaffold does not establish redundancy among working models.
